# SAS Scanner v1.0

نسخة Windows الجاهزة للتشغيل من SAS Scanner.

## التشغيل

شغّل `SAS_Scanner_v1.0.exe`. قد يتطلب فحص اتصالات جميع العمليات تشغيله بصلاحيات المسؤول.

البرنامج يعرض اتصالات الشبكة التي يصنفها كمشبوهة، ويكرر الفحص كل ثلاث ثوانٍ. التصنيف مبني على قواعد بسيطة داخل البرنامج ولا يثبت وحده وجود برمجية ضارة أو سلامة الجهاز.
